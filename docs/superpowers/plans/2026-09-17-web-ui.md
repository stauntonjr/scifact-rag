# SciFact Evidence-Inspection Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one packaged, responsive evidence-inspection page to the existing loopback FastAPI service without creating a second application architecture.

**Architecture:** A presentation-only FastAPI router serves packaged HTML, CSS, and JavaScript at `/` and fixed `/assets/` paths. The browser uses same-origin `fetch` calls to the existing versioned `/v1/search` and `/v1/ask` endpoints; all retrieval, generation, validation, and citation authority remains in the accepted application and HTTP layers.

**Tech Stack:** Python 3.12, FastAPI, `importlib.resources`, native HTML/CSS/JavaScript, httpx/pytest, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-09-17-web-ui-design.md`

## Global Constraints

- Governing work item: GitHub Issue #13.
- Capability disposition: activate the existing `web-interface` skeleton; do not build a parallel UI capability.
- Solution disposition: adapt the existing FastAPI adapter and native browser APIs; add no runtime dependency.
- Serve the UI from the existing `api` service and existing `127.0.0.1:8090:80` publication.
- Add no backend endpoint beyond `/`, `/assets/scifact.css`, and `/assets/scifact.js` presentation routes.
- Browser data calls remain exactly `POST /v1/search` and `POST /v1/ask` with their current schemas.
- Do not change retrieval, ranking, context selection, generation, prompts, evidence, citations, or application defaults.
- Do not add Node, a frontend build system, external browser assets, another container, CORS, authentication, TLS, or non-loopback exposure.
- Render corpus/model text with DOM text properties and never as HTML.
- Keep one focused UI test module; do not create a broad browser-testing framework.
- Exactly one complete `make smoke` gate is executed for the final current attempt.
- Live browser evidence establishes local loopback operation only, not production readiness.

- [ ] **Step 4: Implement the presentation-only router**

Create `src/scifact_rag/web/__init__.py` with this public shape:

```python
from __future__ import annotations

import json
from functools import lru_cache
from importlib.resources import files

from fastapi import APIRouter
from fastapi.responses import HTMLResponse, Response

from ..generation import GenerationContextStrategyName
from ..strategies import DEFAULT_RETRIEVAL_STRATEGY, RetrievalStrategyName

_CONFIG_MARKER = "__SCIFACT_CONFIG__"


@lru_cache(maxsize=3)
def _asset_text(name: str) -> str:
    return files(__package__).joinpath(name).read_text(encoding="utf-8")


def _configuration_json() -> str:
    value = json.dumps(
        {
            "retrieval_strategies": [strategy.value for strategy in RetrievalStrategyName],
            "default_retrieval_strategy": DEFAULT_RETRIEVAL_STRATEGY.value,
            "context_strategies": [strategy.value for strategy in GenerationContextStrategyName],
            "default_context_strategy": GenerationContextStrategyName.WHOLE_DOCUMENT.value,
        },
        separators=(",", ":"),
    )
    return value.replace("&", "\\u0026").replace("<", "\\u003c").replace(">", "\\u003e")


def create_web_router() -> APIRouter:
    router = APIRouter(include_in_schema=False)
    index = _asset_text("index.html").replace(_CONFIG_MARKER, _configuration_json())
    stylesheet = _asset_text("scifact.css")
    script = _asset_text("scifact.js")

    @router.get("/", response_class=HTMLResponse)
    def web_index() -> HTMLResponse:
        return HTMLResponse(index, headers={"Cache-Control": "no-store"})

    @router.get("/assets/scifact.css")
    def web_stylesheet() -> Response:
        return Response(stylesheet, media_type="text/css")

    @router.get("/assets/scifact.js")
    def web_script() -> Response:
        return Response(script, media_type="text/javascript")

    return router
```

In `src/scifact_rag/http_api.py`, import `create_web_router` and immediately after constructing the
FastAPI app call:

```python
app.include_router(create_web_router())
```

Do not pass the resolver to the router.

- [ ] **Step 6: Implement browser request and rendering behavior**

In `scifact.js`:

1. Parse the configuration script and populate both selects from its arrays.
2. Use the selected defaults without substituting browser-owned defaults.
3. On Search, send `search-request/v1` to `/v1/search`; on Answer, send `ask-request/v1` to
   `/v1/ask` and include `context_strategy`.
4. Set limit max to 100 for Search and 20 for Answer before `form.reportValidity()`.
5. Clear old results and disable controls during one active request.
6. Validate the top-level response shape and required evidence fields before rendering.
7. Build every result node with `document.createElement` and `.textContent`.
8. Preserve evidence order and create one stable evidence-card ID per `doc_id`.
9. Require every answer citation to occur in the evidence ID set before rendering citation links.
10. Render exact insufficiency only when text is `insufficient evidence` and both arrays are empty.
11. Map 422 to `Request validation failed`; map fetch/HTTP 500/non-JSON failures to
    `The service is temporarily unavailable`; map shape/citation mismatches to
    `The response did not match the expected contract`.
12. Never display caught exception text or raw response bodies.
